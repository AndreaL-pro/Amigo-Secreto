<h1> Amigo Secreto</h1>

- 🎁 Amigo Secreto

¡Bienvenido a Amigo Secreto! Esta herramienta te ayudará a organizar de manera fácil y rápida el tradicional juego de amigo secreto. Solo necesitas incluir los nombres de los participantes, y el sistema se encargará de asignar aleatoriamente un "amigo secreto" para cada persona.

🛠️ Funcionalidades
Agregar los nombres de los participantes.
Generar asignaciones de "amigo secreto" completamente al azar.
Garantizar que nadie se asigne a sí mismo como su propio "amigo secreto".
Exportar la lista de asignaciones para enviarla por correo o mensajes privados.
🚀 ¿Cómo funciona?
Ingresa los nombres de los participantes en el sistema.
Haz clic en el botón "Generar Amigo Secreto".
El sistema realizará el sorteo al azar y mostrará los resultados.
Descarga o copia las asignaciones generadas para compartirlas de manera segura.
